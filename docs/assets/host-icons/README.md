# Host sidebar logos

These marks identify the user's selected server platform. Trademarks belong to
their owners; inclusion does not imply endorsement. The coloured avatar discs
are Shimmer presentation. The vector masters are retained in the asset catalog.

- Bazzite: [official press kit](https://github.com/ublue-os/bazzite/blob/main/press_kit/Bazzite_BW.svg), Apache-2.0. See `Bazzite-Apache-2.0.txt`.
- ChimeraOS: [official artwork](https://github.com/ChimeraOS/chimeraos/blob/master/assets/logo.svg), MIT. See `ChimeraOS-MIT.txt` for its copyright and permission notice.
- macOS: Apple's public `apple.logo` SF Symbol, supplied by the OS.
- Windows: [Simple Icons 11.15.0 Windows 11 mark](https://github.com/simple-icons/simple-icons/blob/11.15.0/icons/windows11.svg), CC0 collection; Microsoft trademark.
- SteamOS: the Steam mark from Simple Icons, identifying the Valve operating system.
- Other Linux marks: [Simple Icons](https://github.com/simple-icons/simple-icons/tree/c71c69e3a27e4436936b831c72643e6513b9f49b/icons), revision `c71c69e3a27e4436936b831c72643e6513b9f49b`. Individual sources, brand guidance, and license overrides are recorded in `simple-icons-metadata.json`. See `Simple-Icons-CC0.md` for the collection license. In particular, Debian is CC-BY-SA-3.0, Gentoo CC-BY-SA-2.5, NixOS CC-BY-4.0, and Garuda GPL-3.0-only. Fedora's brand terms are linked in the metadata.

Artwork geometry is unchanged; SVG path syntax is normalized for Apple CoreSVG.
Except ChimeraOS, the marks are displayed as
monochrome templates (white on a coloured avatar; Tux is black on yellow).

Automatic selection is a hostname suggestion, not verified OS detection.
Users can override it using the server's **Server icon** context menu.
